# 测试版更新日志（Beta）

仅记录 Beta 测试版本。每次 Beta 修改均新增版本号和记录，不覆盖历史条目。

- 锁屏页面改为指纹优先布局，主密码保留为备用解锁方式。
- 首页品牌信息卡片和导航栏视觉优化。
- versionCode：3。
- 测试状态：Actions 构建待核验；指纹需真机验证。

## 1.0.1-beta.1 — 2026-11-10
- 首个可下载 Beta 包。
- 接入 BiometricPrompt 与 Android Keystore 指纹密钥封装流程。
- 测试状态：尚未完成全面真机验证。

## Beta 发布规则
- 每次代码修改递增 Beta 序号和 Android versionCode。
- 每个 Beta 版本使用独立 tag 和 GitHub Pre-release。
- Release 正文必须包含本版本修改、测试状态及已知问题。
