# 页面交互与视觉设计

基线版本：1.0.1-beta.6

## 视觉规范
- 背景 #0B1220；卡片 #142238；强调蓝 #38BDF8、青 #22D3EE。
- 正文浅灰白，辅助文字蓝灰；状态色仅用于成功/警告/错误。
- 圆角 12–24dp；统一线性图标；轻量淡入/滑动，不堆叠发光效果。
- 支持窄屏、横竖屏、系统字体缩放和高对比度。

## 一级导航
底部：首页、笔记、时间线、密码库、我的。锁屏、首次初始化作为独立流程。

## 页面交互
### 初始化与锁屏
首次打开依次设置主密码、确认密码、建立密钥与数据库、询问是否启用指纹。已绑定设备优先显示大号指纹按钮，主密码始终可用。认证失败给出可理解原因，不暴露密钥细节。

### 首页
顶部品牌/保险库状态；统计卡片；快捷新建笔记/密码、搜索、备份；最近编辑与活动列表。空状态引导创建第一篇笔记。

### 笔记列表
顶部搜索和新建；分类筛选、标签筛选、收藏/置顶；卡片显示标题、正文摘要、更新时间；长按进入多选，滑动操作需可撤销。

### 编辑器
标题、Markdown 编辑区、工具栏、编辑/预览切换、附件入口、保存状态。输入停止约 1 秒防抖保存；退出前等待写入完成。保存失败显示重试，不显示“已保存”。

### 时间线
按时间倒序；单条显示版本号、时间、修改原因。版本详情可比较/恢复；比较支持上下对照与新增/删除标记。恢复二次确认并生成新快照。

### 密码库
分类列表和搜索；默认隐藏敏感字段；显示或复制前按设置要求重新验证；复制后定时清理剪贴板；编辑/删除有确认。

### 附件与回收站
附件按笔记/类型筛选，预览和删除；回收站显示删除时间及剩余保留时间，恢复和永久删除分开操作。

### 备份恢复
展示最近成功备份、文件大小和计划；导出需系统文件选择器；导入先验证密码和完整性，再展示数据摘要，用户确认后事务恢复。

### 我的/设置
安全中心、备份、回收站、附件管理、外观、笔记、数据、更新日志、关于。

## 状态与反馈
所有异步操作有加载、成功、失败状态；破坏性操作二次确认；空状态、错误状态和权限拒绝状态均提供下一步操作。
