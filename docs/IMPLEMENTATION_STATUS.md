## 构建与发布策略

- 功能开发期间暂停 main 分支 push / pull_request 自动构建；工作流仅保留手动触发。
- 不提升 versionCode/versionName，不创建新 Beta Release。
- 完成功能和静态检查后恢复自动构建，统一运行测试、Release APK 构建、签名校验和迁移验证，再更新版本日志并发布 Pre-release。
- 在备份/恢复和签名覆盖安装验证完成前，不要卸载现有应用。
